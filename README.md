## Dino Run Game

A simple Dino Run game built with Python's Turtle graphics library.

### Project Structure
- `config.py`: Contains all game configuration constants.
- `entities.py`: Defines the Dino and Obstacle classes.
- `ui.py`: Handles user interface elements like score display and messages.
- `game.py`: Main game logic and loop.
- `dino_game.py`: Entry point to run the game (imports from game.py).
- `hello.python`: A simple "Hello, World!" script.

### How to Run
Run `python dino_game.py` to start the game.

### Controls
- Space or Up Arrow: Jump
- R: Restart after game over

### Features
- Jump over obstacles (cacti and birds).
- Increasing speed and score.
- Game over and restart functionality.
